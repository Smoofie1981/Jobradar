# Jobradar 0.2 – Live-Suche

Private Android-App für die persönliche Jobsuche.

## Diese Version tut tatsächlich etwas
- Live-Abruf aus der Jobsuche der Bundesagentur für Arbeit
- Suche Magdeburg + 50 km, Stendal als Ausnahme
- Suchbegriffe: Projektmanagement, Projektleitung, Projektsteuerung, Infrastruktur, Vergabe, Ausschreibung, technische Koordination, Maschinenbau
- zusätzliche Arbeitgeber-Suchen für SWM, Autobahn GmbH und AIB / Immobilien- und Baumanagement
- Ausschlüsse: LSBB, Lämpe Mössner Sinto, Sozialpädagogik, reine Elektrotechnik-Rollen
- Scoring mit E11–E13 / vergleichbaren Hinweisen, Unbefristung, Aufgabenbezug und Arbeitgeber-Priorität
- echte Links auf die Originalanzeige bzw. BA-Detailseite
- lokale Speicherung mit Status Neu / Interessant / Beworben / Ausgeblendet
- tägliche Hintergrundsuche über WorkManager
- Benachrichtigung bei neuen passenden Treffern (wenn Android-Benachrichtigungen erlaubt sind)

## Noch nicht in 0.2
INTERAMT und das Karriereportal Sachsen-Anhalt werden noch nicht direkt separat abgefragt. Viele öffentliche Stellen erscheinen bereits über die BA-Suche; separate Quellen können anschließend ergänzt werden.
